# EvolveTS Gate 1 learned-updater probe (dev)

## What this is

Two learned updaters — `ridge_stack`, a shrunk online least-squares stacker with exponential forgetting, and `loss_gate`, an online ridge model that predicts each expert's next loss and gates on the predictions — were replayed over the dev pools covered by the first complete Gate 1 tune run (`gate1-tune-20261013T151300Z-b36261f7`): ETTh1, ECL and synthetic-dev, each with the classical expert pool (`simple`) and with the three foundation models added (`simple+foundation`). Each updater's 6-point grid was selected by lowest dev MASE in its own recorded run, and its per-series dev MASE was compared with that tune run's best tuned hand-designed baseline through 95 % paired bootstrap intervals. MASE, lower is better; every number comes from the ledgers of those runs and the report generated from them.

The report's `### Probe verdicts` table, copied verbatim:

A learned updater beats the best tuned baseline outside the 95 % interval on: synthetic-dev/simple, with ridge_stack.

## Caveats (faithful reading)

- Dev numbers: every selection was made on these same series, both the baselines' (in the tune run) and the learned updaters' (in the probe runs), so both sides' fit is flattered.
- ETTh1 and ECL results with foundation models in the pool are leakage-risk (a foundation model may have seen these datasets in pretraining).
- Each verdict is one of several comparisons (6 pools x 2 learned updaters); no multiple-comparison correction is applied.
- Only convex-weight learners were tried (two of them, with 6 grid points each); learners that output forecasts directly are not tested here.
- The baselines' grid-edge note from the first run, restated from this report's tables: Hedge `eta` = 0.015625, the lowest `ETA_GRID` value, on ETTh1 simple, ETTh1 simple+foundation and ECL simple; Fixed-Share `alpha` = 0.0001, the lowest `ALPHA_GRID` value, on ECL simple+foundation and synthetic-dev simple+foundation.

## Notes

- These are dev numbers: each selected configuration was chosen on these same series, so the dev gaps favour that baseline's fit.
- The expert-pool oracles bound single-expert selection only and are not a floor for weighted combinations.
- The Gate 1 decision is the owner's.
- Gain is the best tuned baseline's per-series dev MASE minus the learned updater's; positive favours the learned updater. `beats` means the whole 95% paired bootstrap interval is above zero.
- Both the baselines and the learned updaters were selected on these same dev series; the configurations column shows how many grid points each had.
- Each verdict is one of several comparisons (pools x learned updaters); no multiple-comparison correction is applied.
- The learned updaters return convex weights over the pool (the arena's updater interface); learners that output forecasts directly are not tested here.
